agy-swap — Google Antigravity CLI Account Switcher & Quota Monitor

High-performance native account switcher and real-time quota monitor for Google Antigravity CLI (agy). Built in Go with instant sub-millisecond execution and native OS vault security.

Quick Installation

Install agy-swap on macOS, Linux, or Windows with a single command:

# Homebrew (macOS)
brew install aklkbqx/agy-swap/agy-swap

# macOS / Linux
curl -fsSL --proto '=https' --tlsv1.2 https://raw.githubusercontent.com/aklkbqx/agy-swap/main/install.sh | bash

# Windows PowerShell
irm https://raw.githubusercontent.com/aklkbqx/agy-swap/main/install.ps1 | iex

Key Features & Architecture

  • Instant Account Switching: Zero-latency session rotation between multiple Google Antigravity accounts.
  • Live Quota & Cooldown Tracking: Proactive tracking for Gemini and third-party model limits and reset countdowns.
  • Hardware-Backed OS Vault: Secure token storage in macOS Keychain, Windows Credential Manager, and Linux Secret Service.
  • Adaptive Terminal UI (TUI): Full interactive terminal interface with Command Palette (Ctrl-K / :).
  • System Doctor Diagnostics: agy-swap doctor automated health verification in one command.

CLI Quick Reference

agy-swap                   # Launch interactive TUI
agy-swap add               # Connect a new account via OAuth browser flow
agy-swap switch dev@me.com # Switch active account by email or number
agy-swap next              # Auto-switch to next account with available quota
agy-swap limits            # View real-time quota and cooldown breakdown
agy-swap doctor            # Run comprehensive system diagnostics

Frequently Asked Questions

What is agy-swap?

agy-swap is a lightweight, high-performance Go CLI utility designed for developers using Google Antigravity CLI (agy) to seamlessly switch developer accounts, monitor model quotas, and manage API sessions securely.

How do I switch Google Antigravity accounts?

You can run agy-swap to open the interactive terminal UI, or execute agy-swap switch <email> directly from your terminal or shell scripts.
