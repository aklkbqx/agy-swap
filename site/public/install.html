Install agy-swap

Native account switcher and quota monitor for Google Antigravity CLI (agy). Each installer verifies the binary against published SHA-256 checksums before running it.

macOS / Linux

curl -fsSL --proto '=https' --tlsv1.2 https://raw.githubusercontent.com/aklkbqx/agy-swap/main/install.sh | bash

Go (any platform)

go install github.com/aklkbqx/agy-swap/cmd/agy-swap@latest

Windows PowerShell

irm https://raw.githubusercontent.com/aklkbqx/agy-swap/main/install.ps1 | iex

Corporate proxy / TLS inspection

If a corporate proxy rewrites TLS and curl fails certificate checks, SHA-256 verification of the downloaded binary still runs:

curl -k -fsSL https://raw.githubusercontent.com/aklkbqx/agy-swap/main/install.sh | AGY_SWAP_INSECURE=1 bash
