# v2.11.5 release hardening plan

**Goal:** Ship v2.11.5 so that published executables use a patched Go toolchain, `go install` resolves the current release, and release assets can only come from a clean annotated tag.

**Issues:** [#22](https://github.com/aklkbqx/agy-swap/issues/22) security toolchain and dependencies, [#23](https://github.com/aklkbqx/agy-swap/issues/23) `go install` module path, [#24](https://github.com/aklkbqx/agy-swap/issues/24) release provenance. Milestone [v2.11.5](https://github.com/aklkbqx/agy-swap/milestone/4). Site metadata follows in the private Site repository.

## Findings (observed 2026-10-12 against v2.11.4)

| Finding | Evidence |
| --- | --- |
| Executables built with Go 1.27.0 | `go version -m` on the published `linux_amd64` and `windows_amd64.exe` assets |
| Nine reachable standard-library vulnerabilities, fixed in Go 1.27.2 | `govulncheck ./...`: GO-2026-6603, 6605, 6607, 6608, 6610, 6611, 6612, 6613, 6617 via `internal/app/oauth.go` and `internal/app/cli.go` HTTP paths |
| `go install …/cmd/agy-swap@latest` installs v1.8.2 | `go list -m github.com/aklkbqx/agy-swap@latest` → v1.8.2; `@v2.11.4` → "module path must match major version" |
| Assets record a dirty pre-tag source | Asset build info: `v1.8.3-0.20261011092332-9f19a0be9b00+dirty`; Go source differs from the tag only in the overridden version constant |
| Lint is not enforced | golangci-lint is not installed, so `make lint` fell back to vet; one unannotated ST1005 finding in `internal/app/windows_session.go` |
| `go.mod` not tidy, old `x/sys`/`x/term` | `go mod tidy -diff`; `go list -m -u all` |

## Constraints

- Patch release: behavior, storage and CLI are unchanged; only the module path, toolchain floor, dependencies and release tooling change.
- Standard library only for the new release checks (`debug/buildinfo`, `go/version`). Linters and govulncheck run as pinned `go run` tools and are not module dependencies.
- No GitHub Actions; release builds stay on the macOS release builder. Production Site image stays `:latest`.
- Owner review gate before any commit, tag, push, release or image publication.

## Known limits

- The legacy path `github.com/aklkbqx/agy-swap/cmd/agy-swap` can only resolve v1 versions; it keeps returning v1.8.2. Only the v2 path receives releases.
- `go install` compiles with the local toolchain: the go command does not apply the module's `toolchain` line to `go install pkg@version` (observed after publication). Release builds refuse an older compiler. Follow-up: [#26](https://github.com/aklkbqx/agy-swap/issues/26).
- Previously published v2.11.4 assets are not rebuilt; v2.11.5 supersedes them as the only supported release.
