# v2.12.0 delivery evidence

Owner approved the reviewed candidate and v2.12.0 publication and deployment on 2026-10-16. The [Release](https://github.com/aklkbqx/agy-swap/releases/tag/v2.12.0) was published at 2026-10-16T09:00:04Z with six platform binaries and checksums. Annotated immutable tag `v2.12.0` is on commit `52f5274`, the merge of [PR #51](https://github.com/aklkbqx/agy-swap/pull/51). A matching immutable Site tag was published.

## Scope

- Metadata-only Tool release. The command-line tool and TUI are unchanged; the version moves in lockstep with the redesigned website (flat operator deck, scroll-driven terminal demo, plain explanation, four locales).
- Regenerated TUI story frames carry the new version string only.

## Verification

- `make qa`: tests, race detector, vet, lint, TUI smoke at four sizes passed. `make vuln`: no reachable vulnerabilities. Site build and 70 of 70 tests passed.
- `make release-assets` ran from tag `v2.12.0` with build ID `release-v2.12.0`; every asset records `go1.27.2`, `github.com/aklkbqx/agy-swap/v2` and `v2.12.0`. GitHub asset digests match `checksums.txt`.
- Homebrew tap updated. Mac active path `/opt/homebrew/bin/agy-swap` reports `agy-swap v2.12.0`, SHA-256 equal to the darwin/arm64 asset.
- Public module proxy: `@latest` resolves to v2.12.0 and `go install` builds with go1.27.2.
- Site published; `make site-verify-live VERSION=2.12.0` matched production (endpoints, installer redirects and versions, demo 404, every built file byte for byte), and the live site reports v2.12.0. A browser check of the live page showed the new headline, no horizontal overflow and no canvas element.

## Limits

- `make release-check` ran its Tool and Site steps; its final local preview was replaced by the release smoke test that `make site-release` runs on the tagged image.
- Only Chrome was used for the live browser check. Browsers without scroll-driven CSS show the finished static page.
