## Limits

- `go install` compiles with the installer's local Go toolchain: the module's `toolchain` line does not apply to `go install pkg@version` (the proxy check above, on Go 1.27.0, recorded `go1.27.0`). Published binaries use Go 1.27.2. Follow-up: [#26](https://github.com/aklkbqx/agy-swap/issues/26).
- The unsuffixed path `github.com/aklkbqx/agy-swap/cmd/agy-swap` can only resolve v1 versions and still returns v1.8.2.
- Windows installation was not exercised in this release; Windows assets are verified by checksum and build information. The v2.11.4 native installer regressions are unchanged.
- v2.11.4 assets are not rebuilt; v2.11.5 is the only supported release. Prior immutable releases remain available for rollback.
