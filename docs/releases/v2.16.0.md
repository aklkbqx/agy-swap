## Scope

- macOS: switching accounts no longer asks for the keychain password every time; the saved token is updated without resetting the item's access list (#68).
- Switching asks first, through one dialog component used for every question, and repaints in place instead of blanking the screen (#70).
- The selection is a full-height orange band; the live account carries a blue dot and `ACTIVE`, so green only describes quota (#69).
- A solid frameless layout: header and footer bars, equal margins, a black body, quota cards, and a centred 160-column frame on larger terminals. Background refreshes are quiet.
- Motion for selection, meters, dialogs, toasts, a manual refresh and the active dot; `AGY_SWAP_REDUCED_MOTION=1` turns it off. Only changed rows are repainted (#71).
- Site: legend, walkthrough and live-demo copy in English, Thai, Japanese and Chinese describe the new screen; story frames regenerated.
