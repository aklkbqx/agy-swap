## Scope

- [#50](https://github.com/aklkbqx/agy-swap/issues/50): Gemini quota did not show. Google's quota summary now returns only the Claude and GPT group for the accounts checked (Free and Ultra tiers), while the model list still carries the Gemini quota per model. agy-swap builds the Gemini group from the model list when the summary has none. The model list does not name the window, so a reset within five hours is read as the 5-hour limit and a later reset as weekly.
- [#55](https://github.com/aklkbqx/agy-swap/issues/55): a limit that Google marks disabled (for example the 5-hour limit while the weekly limit is used up) was drawn as 100% remaining. It is now skipped.
- `AGY_SWAP_QUOTA_DEBUG=1` prints which quota buckets were kept or skipped and why, the field names of Google's answer and the per-model quota (percentages and reset times only; no tokens or account identifiers). It is off by default.
- Site: version alignment only.

- Site published; `make site-verify-live VERSION=2.12.2` matched production byte for byte, and the live site reports v2.12.2.

## Limits

- The Gemini limits read from the model list show one value per account. Google's weekly Gemini figure that the `agy` CLI shows was not found in any endpoint agy-swap calls, so an account may show only the 5-hour Gemini limit.
- The window inference rests on the reset time, not on a field Google reports.
