# v2.11.6 delivery evidence

Verified on 2026-10-13 after owner approval of the reviewed candidate. [Release and seven assets](https://github.com/aklkbqx/agy-swap/releases/tag/v2.11.6) published at 2026-10-12T17:31:40Z. Tool commit `8c9fd87`, annotated tag `v2.11.6` on that commit; [PR #31](https://github.com/aklkbqx/agy-swap/pull/31) merged afterwards as `c67bafe`. Assets were published before the merge promoted the default installers.

## Scope

- [Install #26](https://github.com/aklkbqx/agy-swap/issues/26): `go.mod` declares `go 1.27.2`. `go install` applies the go directive but not the `toolchain` line used in v2.11.5, so source installs now build with the patched standard library. Release tooling reads the floor from the newer of the two.
- [Tests #27](https://github.com/aklkbqx/agy-swap/issues/27): end-to-end tests for `switch`, `remove`, `status`, `list`, `logout` and `add --token -`.
- Site: Go 1.27.2 requirement in all four locales (tested against `go.mod`); explicit tested size limit for the lazy desktop-only 3D scene chunk. Product behavior, storage and commands are unchanged.

## Candidate verification

Tests written first: the go-directive floor test and the floor fallback test failed before the change. New command coverage (previously 0%): `switch` 80%, `status` 87.5%, `logout` 75%, `add` 72.7%, `remove` 68%, `list` 60.4%. `make qa` passed (tests, race detector, vet, golangci-lint 0 issues, TUI smoke at four sizes); govulncheck reported no vulnerabilities; `go mod tidy -diff` was empty. Site: 76/76 tests, build without the chunk warning, production-equivalent preview reporting v2.11.6.

## Installation and live delivery

- `make release-assets` ran from tag `v2.11.6`; every asset records `go1.27.2`, `github.com/aklkbqx/agy-swap/v2` and `v2.11.6`. GitHub asset digests match `checksums.txt`.
- Homebrew tap updated. Mac active path `/opt/homebrew/bin/agy-swap`: `agy-swap v2.11.6 (release-v2.11.6)`, Go 1.27.2, SHA-256 equal to the darwin/arm64 asset.
- Public module proxy, isolated GOPATH, local Go 1.27.0, default `GOTOOLCHAIN=auto`: `go list -m …/v2@latest` returned v2.11.6 and `go install …/v2/cmd/agy-swap@latest` produced `agy-swap v2.11.6 (dev)` built with **go1.27.2**.
- Site source, tag and `:latest` image published; `make site-verify-live VERSION=2.11.6` matched production in about 17 seconds including the Watchtower rollout (endpoints, installer redirects and promoted versions, demo 404, every built file byte for byte).
- History inventory records 49 Tool tags, 48 published stable Releases; latest stable v2.11.6.

## Limits

- Native Windows installation is not yet verified for this release: the Windows test machine was unreachable. Tracked in [#28](https://github.com/aklkbqx/agy-swap/issues/28); Windows assets are verified by checksum and build information.
- `internal/app` total coverage rose from 46.9% to 48.4%; the package total is dominated by TUI rendering and updater code outside this release's scope.
