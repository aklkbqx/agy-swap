Owner approved the change and v2.12.1 publication and deployment on 2026-10-16. The [Release](https://github.com/aklkbqx/agy-swap/releases/tag/v2.12.1) was published at 2026-10-16T10:18:24Z with six platform binaries and checksums. ## Scope

- Metadata-only Tool release. The command-line tool and TUI are unchanged. The story-frame fixture gains a 63-column layout (the widest in which the TUI still lists every account) that the website uses so its pinned terminal fills a wide stage.

## Verification

- `make qa` and `make vuln` passed; Site build and 71 of 71 tests passed.
- `make release-assets` ran from tag `v2.12.1` with build ID `release-v2.12.1`; every asset records `go1.27.2`, `github.com/aklkbqx/agy-swap/v2` and `v2.12.1`. GitHub asset digests match `checksums.txt`.
- Homebrew tap updated; `/opt/homebrew/bin/agy-swap` reports `agy-swap v2.12.1`, SHA-256 equal to the darwin/arm64 asset.
- Public module proxy resolves `@latest` to v2.12.1 and `go install` builds with go1.27.2. The first evidence run failed this check because the proxy had not yet listed the tag; it passed on rerun.
- `make site-verify-live VERSION=2.12.1` matched production byte for byte on rerun (the first run ran while the container was being replaced). A browser check on the live page showed the 63-column frame filling the stage with no horizontal overflow.

## Limits

- Tablet widths (600 to 1023px) still show side space because the stage height is fixed. Phones keep the 48- and 40-column frames; they were not re-measured in this release.
