## Scope

- Native `agy` installer (#85): `agy-swap install-agy` downloads the official Google Antigravity CLI for the current OS and architecture, verifies its SHA-512 checksum before extracting, runs `agy install` and applies the session launcher guard. It is also reachable from the TUI Command Palette under `System` and from `agy-swap add` when no `agy` is installed.
- Custom installation paths (#85): `install-agy --dir <path>` saves the directory in `settings.json` (`targets.agy`). `add`, `run now`, `target list`, `target check` and the launcher guard resolve `AGY_SWAP_AGY_BIN`, `settings.targets.agy`, `PATH` and the standard per-OS locations, and keep relative or external symlinks intact.
- Windows SSH sessions (#85): when Windows Credential Manager returns `ERROR_NO_SUCH_LOGON_SESSION` (`1312`) in a passwordless SSH logon, switching and clearing write `cache/antigravity-keyring-unavailable` and fall back to the `0600` OAuth token files instead of failing. Verified on a Windows machine over Wake-on-LAN and SSH.
- Windows installer (#85): `install.ps1` adds the installation directory to the user `Path`, removes stale `agy-swap.exe` copies from earlier `PATH` entries and runs `--sync-session` after installing.
- `account migrate --force` (#85): accounts already in `vault.json` are no longer counted as remaining in legacy storage.
