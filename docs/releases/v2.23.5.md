# v2.23.5 delivery evidence

Published 2026-11-12 with owner authorization. Keeps the manual refresh light inside the header bar, wraps live frames in synchronized-output markers, lets a manual refresh replace a background quota read, shows each account's quota as it arrives, coalesces mouse-wheel bursts and handles pending input before frame timers (#106). Writes frames outside the input loop, keeps only the newest unsent frame and repaints only the changed part of a row, so keys and quitting respond while the terminal reads output slowly (#107).

## Known limits

- The slow-terminal fix in #107 is covered by tests on a rate-limited pseudo-terminal. It was not tested on Windows.
- After installing the candidate, the owner still saw stalls in a terminal multiplexer on macOS. One measured run there showed agy-swap handling each key within 2 ms and the terminal taking output without delay, while a group of key presses reached agy-swap together after a 10 second gap. The cause of that gap was not established.
