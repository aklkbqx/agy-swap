## Scope

- Keychain bypass (#79): switching accounts, clearing the active session, and logging in a new account no longer call `/usr/bin/security` or prompt for the login keychain password on macOS and Linux. `agy-swap` maintains `~/.gemini/antigravity-cli/cache/antigravity-keyring-unavailable` and configures the `~/.local/bin/agy` launcher (`shouldBypassKeyring`) so Antigravity's `CompositeTokenStorage` and `agy-swap` both use the `0600` file-backed session store (`antigravity-oauth-token`) directly instead of reading stale Keychain items.
- Multi-workspace session guard (#79): a background `agy` process refreshing its OAuth token in another folder no longer switches newly opened workspaces away from the active account chosen in `agy-swap`. `agy-swap --sync-session` and automatic startup reconciliation harvest refreshed tokens into the account vault by matching `refresh_token` and restore the active account selected in `google_accounts.json`.
- Automatic launcher shim (#79): when `~/.local/bin/agy` is present, `agy-swap` automatically wraps or upgrades the launcher to run `agy-swap --sync-session` before and after `agy` with zero manual configuration.
- Site: story frames and release metadata updated to `v2.17.1`.
